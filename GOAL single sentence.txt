GOAL (single sentence):
Build a replacement Android messaging app (starting from an Empty Views Activity template) with standard messaging features plus an Automation fragment that launches another app, overlays a controllable automation UI using Accessibility features, performs preprogrammed UI interactions, extracts a name from the target app, combines it with a note, sends a local notification, and appends the combined note to the message list.

TOP-LEVEL REQUIREMENTS:
1. Use the existing Empty Views Activity project as the working directory. Do not change template type.
2. Language: Kotlin. Use AndroidX / Jetpack components. Target latest SDK available.
3. The resulting app must run on real physical Android devices.
4. All permissions (Accessibility, overlay) must be explicitly requested with clear UX. No bypassing OS restrictions.
5. Build in phases. After each phase produce:
   - A runnable APK
   - A test checklist
   - Test results
   Only proceed when all tests pass.

SECURITY / PRIVACY REQUIREMENTS:
- Automation must be explicit and user-initiated.
- No stealth automation in background.
- Provide a warning dialog before interacting with any third-party app.
- Maintain transparency: show visible overlay controls and STOP button.

FEATURES:

1. Messaging Core (Fragments + Room DB)
- Conversations list
- Conversation detail
- Persisted messages in Room DB
- Ability to append a new message manually

2. Automation Fragment (UI & Functionality)
UI:
- Spinner with Task1, Task2, Task3
- Text input
- Initiate button
- Status log area

Automation Flow:
1. Validate user input.
2. Request missing permissions (Accessibility / overlay) with explanation screens.
3. Launch the target app (default package configurable in Settings).
4. Show a visible overlay controller with:
   - Current step
   - Logs
   - STOP button
5. Use an AccessibilityService (enabled by the user) to:
   - Perform pre-programmed UI interactions (clicks, swipes)
   - Extract a name from screen content (AccessibilityNode first, OCR optional fallback)
6. Combine extracted name with template note.
7. Send local notification.
8. Insert combined note into messaging DB.
9. Show success/failure in Automation fragment log.
